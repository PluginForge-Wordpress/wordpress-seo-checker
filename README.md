# PluginForge WordPress SEO Checker

Free website and WordPress SEO analysis tool by PluginForge.

Analyze a public URL and receive a shareable SEO report with checks for titles, meta descriptions, headings, canonical URLs, robots directives, hreflang, Open Graph, Twitter/X Cards, structured data, image ALT attributes, internal and external links, robots.txt, sitemaps, HTTPS and indexability.

## Features

- Real-time public URL analysis
- SEO score and issue detection
- Title and meta description checks
- H1/H2 structure analysis
- Canonical and hreflang detection
- Open Graph and Twitter/X metadata
- JSON-LD / Schema.org inspection
- Image ALT analysis
- Internal and external link analysis
- robots.txt and XML sitemap checks
- HTTPS, viewport and HTML language checks
- Indexability analysis
- Shareable public reports
- SSRF protection for submitted URLs
- Per-IP request rate limiting

## Security

The analyzer validates submitted URLs before fetching them and blocks local, loopback, private and reserved network destinations.

## Source

This repository contains the PluginForgeTools module used by the PluginForge website.

It is designed to run inside an InnoShop-based application and is not a standalone WordPress plugin.
